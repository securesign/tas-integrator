# tas-integrator

Agent skills for scanning CI/CD environments and generating Trusted Artifact Signer (TAS) integration blueprints.

## Skills

| Skill | Description |
|-------|-------------|
| `scan-jenkins` | Scan a Jenkins environment for TAS integration readiness |
| `scan-gitlab` | Scan a GitLab CI environment for TAS integration readiness |
| `export-blueprint` | Format raw blueprint data into a Markdown or YAML integration blueprint |
